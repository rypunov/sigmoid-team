# Loss.py — Функции потерь для PINN уравнения состояния

## Назначение

Модуль реализует **физически-информированную функцию потерь** (Physics-Informed Loss) для обучения нейросетевой модели уравнения состояния (EOS). Помимо стандартной ошибки восстановления табличных данных (давление `P` и энергия `E`), лосс содержит **термодинамические регуляризаторы**, штрафующие нарушения физических законов.

## Зависимости

- `torch`, `math`
- `MLP.grad` — обёртка над `torch.autograd.grad` с `create_graph=True` (необходима для вычисления вторых производных).

## Основная функция

### `eos_loss_fn(model, rho, T, p_target, e_target, normalizer)`

Вычисляет 5 компонентов лосса.

**Параметры:**

| Аргумент | Тип | Форма | Описание |
|---|---|---|---|
| `model` | `nn.Module` | — | Сеть `[B, 2] → [B, 2]` (вход: `[rho_n, T_n]`, выход: `[p_n, e_n]`). |
| `rho` | `Tensor` | `[B, 1]` | Нормализованная плотность. Включается `requires_grad=True`. |
| `T` | `Tensor` | `[B, 1]` | Нормализованная температура. Включается `requires_grad=True`. |
| `p_target` | `Tensor` | `[B, 1]` | Целевое нормализованное давление. |
| `e_target` | `Tensor` | `[B, 1]` | Целевая нормализованная энергия. |
| `normalizer` | `EOSNormalizer` | — | Содержит `params["rho"|"T"|"P"|"E"]["mean"|"std"]`. |

**Возвращает** словарь с компонентами:

| Ключ | Формула | Смысл |
|---|---|---|
| `"pde"` (`L_p`) | `mean((p_pred − p_target)²)` | MSE по давлению (норм.). |
| `"bc"` (`L_e`)  | `mean((e_pred − e_target)²)` | MSE по энергии (норм.). |
| `"ic"` (`L_mod`) | `mean(relu(−dP/dρ)²)` | Механическая стабильность: `dP/dρ ≥ 0`. |
| `"L_C"` | `mean(relu(−dE/dT)²)` | Положительная теплоёмкость: `dE/dT ≥ 0`. |
| `"L_th"` | `mean(residual²) / (mean(P²)+ε)` | Уравнение Максвелла: `T·dP/dT + ρ²·dE/dρ − P = 0`. |

## Ключевые моменты реализации

### 1. Дифференцирование в нормализованном пространстве

Сеть обучается на нормализованных `ρ, T`, поэтому автоград даёт `dp/dρ_n` и `dp/dT_n`. Физические производные восстанавливаются по **chain rule**:

```
T · dP/dT  =  T_phys · (P_phys · ln10 · σ_P / σ_T) · dp_dT_n
ρ² · dE/dρ =  ρ_phys · (σ_E / (ln10 · σ_ρ)) · de_drho_n
dP/dρ      =  P_phys · (σ_P / (ln10 · σ_ρ · ρ_phys)) · dp_drho_n
```

Множитель `ln10` появляется потому, что `ρ` и `P` нормализованы **в log10-шкале**:

```
ρ_phys = 10^(ρ_n · σ_ρ + μ_ρ) − 1e-12
P_phys = 10^(p_n · σ_P + μ_P) − 1e-12
```

### 2. Знак теплоёмкости

Поскольку `σ_E, σ_T > 0`, знак `de_dT_n` совпадает со знаком `dE/dT`. Поэтому `L_C` можно считать **без обратного преобразования**, что дешевле и численно устойчивее.

### 3. Относительная нормировка `L_th`

Резидуал Максвелла нормируется на `mean(P_phys²)`, чтобы слагаемые `T·dP/dT`, `ρ²·dE/dρ` и `P` были безразмерными и сопоставимы по величине с остальными лоссами.

## Совместимость с тренером

Возвращаемые ключи `pde`, `bc`, `ic` соответствуют ожиданиям `PINN_Model_Trainer.train()`; `L_C` и `L_th` — дополнительные регуляризаторы, взвешиваемые в словаре `scale`.

## Подводные камни

- `p_target` и `e_target` **должны быть нормализованы** тем же `normalizer` — иначе `L_p`/`L_e` несопоставимы с регуляризаторами.
- Малые `P_phys` (близкие к нулю) могут давать взрывные градиенты через `1/P_phys` в `dP/dρ`; слагаемое `−1e-12` при обратном преобразовании `10^x` частично защищает от нуля.
- Если `ρ_phys → 0`, `ρ² · dE/dρ` в `L_th` может вести себя нестабильно — в рабочем диапазоне EOS это не критично.
