## 📌 Описание проекта

Проект представляет собой суррогатную модель уравнения состояния (EOS) для алюминия. Цель — заменить тяжелые гидродинамические таблицы быстрой и легковесной нейросетью (PINN), которая не только точно предсказывает давление `P` и внутреннюю энергию `E`, но и строго соблюдает фундаментальные термодинамические ограничения (например, положительность скорости звука).

## 🏗 Архитектура решения

Проект разделен на несколько взаимосвязанных модулей:

*   **Подготовка данных (`data_loader.py`, `preprocessor.py`, `eda.py`)** — загрузка сырых данных, разведочный анализ, нормализация и разделение на выборки.
*   **Бейзлайн (`baseline.py`)** — эталонная модель на базе билинейной интерполяции (SciPy) для сравнения.
*   **Нейросетевые модели (`ML_Models/`)**:
    *   `Vanilla.py` — базовая нейросеть (MLP).
    *   `PINN_Al.py` — физически-информированная нейросеть.
    *   `Loss.py` — функции потерь, включая физические ограничения.
    *   `PINN_Model_Trainer.py` — пайплайн обучения PINN.
*   **Оценка и метрики (`evaluate_all.py`, `metrics.py`)** — единый скрипт для инференса, расчета метрик (MAPE, R²) и замера скорости.
## 🚀 Установка и запуск

**1. Клонирование и установка зависимостей:**

```bash
git clone https://git.hackraft.ru/ml-03/ml46280.git
cd ml46280
python -m venv .venv
source .venv/bin/activate  # Для Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

**2. Запуск полного пайплайна (EDA + обучение бейзлайна + метрики):**

```bash
python src/evaluate_all.py
```

*Результаты (JSON с метриками и коэффициенты нормализации) сохраняются в папку `artifacts/`.*

## 🛠 Примеры использования API

Для использования итоговой модели в сторонних приложениях реализован класс-обёртка. Модель экспортирована в **TorchScript** (не требует Python-кода для запуска).

```python
import torch
import numpy as np
from src.wrapper import EOSWrapper

# Загрузка модели и параметров нормализации
model = EOSWrapper(
    model_path="artifacts/models/pinn_compressed.pt",
    norm_path="artifacts/models/normalization.json"
)

# Входные данные (плотность г/см3, температура K)
rho = np.array([2.7, 10.5])
T = np.array([300.0, 1e5])

# 1. Предсказание P и E
P, E = model.predict(rho, T)

# 2. Расчет скорости звука
cs = model.sound_speed(rho, T)

# 3. Проверка на нарушения физики (возвращает массив флагов)
flags = model.check_physics(rho, T)
```
