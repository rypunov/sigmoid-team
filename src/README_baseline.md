# baseline.py — Бейзлайн-модель уравнения состояния на билинейной интерполяции

## Назначение

Модуль реализует **простейший baseline** для задачи EOS: кусочно-билинейную интерполяцию табличных данных `P(ρ, T)` и `E(ρ, T)` по каждой из областей (`OblXX`). Используется как точка отсчёта для сравнения с нейросетевыми моделями (PINN, Vanilla) по точности и скорости.

## Зависимости

- `numpy`
- `scipy.interpolate.RegularGridInterpolator`
- `pickle`
- `pathlib.Path`
- `config.MODEL_DIR` — директория для сохранения/загрузки модели.

## Класс `BilinearEOS`

### Атрибуты

| Атрибут | Тип | Описание |
|---|---|---|
| `interpolators_P` | `list[RegularGridInterpolator]` | Интерполяторы давления для каждой области. |
| `interpolators_E` | `list[RegularGridInterpolator]` | Интерполяторы энергии для каждой области. |
| `bounds` | `list[dict]` | Границы каждой области: `rho_min`, `rho_max`, `T_min`, `T_max`. |

### Метод `fit(regions: list)`

Обучает интерполяторы по списку объектов `EOSRegion` (из `data_loader.py`). Для каждой области:

- Создаётся `RegularGridInterpolator` по сетке `(T, rho)` с методом `"linear"`.
- `bounds_error=False`, `fill_value=None` — экстраполяция за пределами сетки (линейная).
- Сохраняются границы области.

**Важно:** порядок осей — `(T, rho)`, т.е. вход интерполятора — `[[T, rho]]`.

### Метод `predict(rho, T)`

Принимает 1D массивы `rho` и `T` одинаковой длины, возвращает `(P_out, E_out)`.

**Алгоритм:**

1. Для каждой точки ищется **первая** область, в границы которой она попадает. Если найдена — интерполяция в этой области.
2. Если точка не попала ни в одну область — выбирается **ближайшая по центру** область (евклидово расстояние в пространстве `(ρ, T)`), и интерполяция выполняется в ней (с экстраполяцией).

**Особенности:**

- Цикл по точкам на Python — медленно для больших массивов, но приемлемо для baseline.
- Для точек вне всех областей используется экстраполяция `RegularGridInterpolator` (линейная), что может давать отрицательные `P` или `E` — это ожидаемо для baseline.

### Метод `save(path=MODEL_DIR / "baseline.pkl")`

Сериализует весь объект через `pickle`.

### Метод `load(path=MODEL_DIR / "baseline.pkl")` (`@classmethod`)

Загружает объект из pickle.

## Пример использования

```python
from baseline import BilinearEOS
from data_loader import load_raw_regions

regions = load_raw_regions()
model = BilinearEOS()
model.fit(regions)

P, E = model.predict(rho_array, T_array)
model.save()
```

## Ограничения

- **Скорость:** цикл по точкам на Python; для 100k точек может занимать секунды.
- **Качество:** билинейная интерполяция не гарантирует гладкости производных, что важно для физических проверок (`dP/dρ > 0`, `dE/dT > 0`).
- **Экстраполяция:** за границами областей может давать физически некорректные значения.
- **Память:** хранит все интерполяторы и исходные сетки (через замыкание) — при большом числе областей растёт.

## Рекомендации по улучшению

- Векторизовать `predict` (например, через `scipy.interpolate.griddata` или `LinearNDInterpolator` по объединённому набору точек).
- Добавить проверку `P > 0` и `dP/dρ > 0` при экстраполяции.
- Использовать `cKDTree` для быстрого поиска ближайшей области.
