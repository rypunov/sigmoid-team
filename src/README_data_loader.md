# data_loader.py — Загрузка и парсинг табличных данных уравнения состояния

## Назначение

Модуль читает исходные файлы `Obl01.txt … Obl20.txt` с табличными данными EOS, восстанавливает двумерные сетки по `(ρ, T)` и предоставляет два способа доступа:

1. **`load_raw_regions()`** — список объектов `EOSRegion` (по одной области на файл) с 2D-матрицами `P` и `E`.
2. **`load_flat_dataset()`** — «плоский» словарь с 1D-массивами всех точек (удобно для нейросетей и статистики).

## Зависимости

- `numpy`, `pandas`
- `pathlib.Path`
- `src.config.DATA_DIR`, `src.config.N_FILES` — директория с данными и число файлов (по умолчанию 20).

## Класс `EOSRegion`

Хранит одну область.

| Атрибут | Тип | Описание |
|---|---|---|
| `name` | `str` | Имя области, например `"Obl01"`. |
| `rho` | `np.ndarray` (1D) | Уникальные значения плотности (отсортированы). |
| `T` | `np.ndarray` (1D) | Уникальные значения температуры (отсортированы). |
| `P` | `np.ndarray` (2D) | Матрица `(n_T, n_rho)` — давление. |
| `E` | `np.ndarray` (2D) | Матрица `(n_T, n_rho)` — энергия. |
| `grid_type` | `str` | Тип сетки из заголовка (например, `"log-log"`). |

`__repr__` выводит имя и размеры сетки.

## Функция `load_raw_regions() -> list[EOSRegion]`

Читает `N_FILES` файлов `Obl{i:02d}.txt` из `DATA_DIR`.

**Алгоритм для каждого файла:**

1. Открывает файл и ищет строку `"Grid type:"` — извлекает тип сетки (по умолчанию `"log-log"`).
2. Читает данные через `pandas.read_csv`:
   - разделитель — пробельные символы (`sep=r'\s+'`),
   - комментарии — `#` (заголовки),
   - имена колонок — `['rho', 'T', 'P', 'e']`.
3. Восстанавливает 2D-сетку:
   - `rho_uniq = np.sort(df['rho'].unique())`,
   - `T_uniq = np.sort(df['T'].unique())`,
   - `P_2d = df.pivot_table(index='T', columns='rho', values='P').values`,
   - `E_2d = df.pivot_table(index='T', columns='rho', values='e').values`.
4. Создаёт `EOSRegion` и добавляет в список.

**Ожидаемый формат файла:**

```
# Grid type: log-log
# rho T P e
1.0e-3 1.0e3 1.0e-2 1.0e-1
...
```

**Исключения:** `FileNotFoundError`, если файл отсутствует.

## Функция `load_flat_dataset() -> dict`

Собирает все области в один плоский набор.

**Возвращает словарь:**

| Ключ | Форма | Описание |
|---|---|---|
| `"rho"` | `(N_total,)` | Плотность всех точек. |
| `"T"` | `(N_total,)` | Температура всех точек. |
| `"P"` | `(N_total,)` | Давление всех точек. |
| `"E"` | `(N_total,)` | Энергия всех точек. |
| `"region"` | `(N_total,)` | Индекс области (0..N_FILES-1) для каждой точки. |

**Алгоритм:**

- Для каждой области `r`:
  - `rho_grid, T_grid = np.meshgrid(r.rho, r.T)`,
  - `ravel()` — вытягивает 2D в 1D,
  - добавляет `r.P.ravel()`, `r.E.ravel()`,
  - заполняет `region` индексом области.
- Конкатенирует все списки.

**Порядок точек:** соответствует порядку `meshgrid` — сначала все `rho` для первого `T`, затем для второго и т.д., внутри каждой области.

## Пример использования

```python
from data_loader import load_raw_regions, load_flat_dataset

regions = load_raw_regions()
print(regions[0])  # EOSRegion(Obl01, rho: 200, T: 100)

ds = load_flat_dataset()
print(ds["rho"].shape, ds["P"].min(), ds["P"].max())
```

## Особенности и ограничения

- **Пропуски в данных:** `pivot_table` по умолчанию агрегирует дубликаты (`mean`). Если в файле есть дубликаты `(rho, T)` с разными `P`, они усреднятся — для EOS это обычно нежелательно; при необходимости заменить `aggfunc='first'` или валидировать.
- **Сортировка:** `rho_uniq` и `T_uniq` сортируются, но `pivot_table` сортирует индекс и колонки — порядок согласован.
- **Память:** `load_flat_dataset` дублирует данные (2D + 1D) — для 20 областей это может быть заметно.
- **`grid_type`** извлекается, но далее нигде не используется — оставлен для диагностики.
- **`N_FILES`** жёстко задаёт число файлов; при другом наборе данных нужно менять конфиг.

## Рекомендации

- Добавить проверку согласованности сетки: `len(rho_uniq) * len(T_uniq) == len(df)`.
- Валидировать монотонность `P` по `ρ` и `T` при загрузке.
- Для больших датасетов использовать `np.float32` вместо `float64` (экономия памяти).
