# eda.py — Разведочный анализ данных (EDA) для уравнения состояния

## Назначение

Скрипт выполняет **первичный анализ** табличных данных EOS:

- распределения `ρ, T, P, E`;
- сечения `P(ρ)` при фиксированной `T` и `P(T)` при фиксированной `ρ`;
- базовые проверки физической корректности (`P ≥ 0`).

Результаты сохраняются в `FIG_DIR` (из `config.py`).

## Зависимости

- `numpy`, `matplotlib`, `seaborn`
- `config.FIG_DIR` — директория для сохранения графиков.
- `data_loader.load_flat_dataset`, `data_loader.load_raw_regions`.

## Особенности импорта

Скрипт добавляет корень проекта в `sys.path`:

```python
sys.path.append(str(Path(__file__).resolve().parent.parent))
```

Затем импортирует `config` и `data_loader` **без префикса `src.`**. Это делает модуль запускаемым как из корня, так и из подпапки, но ломает пакетный импорт (`from src.eda import ...`). В идеале — использовать относительные импорты и запускать через `python -m src.eda`.

## Функции

### `plot_distributions(ds: dict)`

Строит 4 гистограммы (2×2):

| Subplot | Величина | Лог-шкала |
|---|---|---|
| `[0,0]` | `log10(ρ)` | — |
| `[0,1]` | `log10(T)` | — |
| `[1,0]` | `log10(P)` | — |
| `[1,1]` | `E` | — |

- `bins=100`, `alpha=0.7`.
- Сохраняет в `FIG_DIR / "eda_distributions.png"` (dpi=150), затем `plt.show()`.

**Зачем:** увидеть диапазоны и возможные артефакты (нули, отрицательные значения, «отрывы»).

### `plot_sections(ds: dict, regions: list)`

Строит два сечения:

1. **Изотерма** при `T ≈ 1000 K`:
   - маска `np.isclose(ds['T'], 1000, rtol=0.01)`,
   - сортировка по `ρ`,
   - `plot(ρ, P)` в log-log.
2. **Изохора** при `ρ ≈ 1.0`:
   - маска `np.isclose(ds['rho'], 1.0, rtol=0.01)`,
   - сортировка по `T`,
   - `plot(T, P)` в log-log.

- Сетка `which="both"`, `ls="--"`, `alpha=0.5`.
- Сохраняет в `FIG_DIR / "eda_sections.png"`.

**Зачем:** визуально проверить монотонность `P(ρ)` и `P(T)`, гладкость, возможные разрывы между областями.

**Ограничение:** `regions` принимается, но **не используется** — сечения строятся по плоскому `ds`. Для корректной работы с несколькими областями нужно фильтровать по `ds["region"]`.

### `check_physics(ds: dict)`

Печатает доли точек:

- `P < 0` (физически невозможно),
- `P > 1e-10` (почти все точки).

**Зачем:** быстрая проверка, что в данных нет грубых ошибок.

**Ограничение:** не проверяет `dP/dρ > 0`, `dE/dT > 0` — для этого нужны производные (см. `Vanilla.py` и `metrics.py`).

## Запуск

```bash
python eda.py
```

**Ожидаемое поведение:**

- Загрузит данные (`load_flat_dataset`).
- Построит и покажет 2 фигуры (гистограммы + сечения).
- Выведет доли `P < 0` и `P > 1e-10`.

## Известные проблемы

- **`sys.path`-хак** — см. выше.
- **`plot_sections` не использует `regions`** — параметр оставлен для обратной совместимости.
- **`T = 1000 K` и `ρ = 1.0`** могут отсутствовать в данных — маска вернёт пустой массив, `plot` выдаст предупреждение и пустой график. Стоит добавить проверку `if mask.sum() == 0: print("нет точек")`.
- **`seaborn` импортируется, но не используется** — лишняя зависимость.

## Рекомендации

- Добавить `pairplot` или `heatmap` корреляций `(log ρ, log T, log P, E)`.
- Построить карту `P` в координатах `(log10 ρ, log10 T)` через `plt.scatter` — нагляднее, чем гистограммы.
- Добавить проверку монотонности `P` по каждой оси внутри каждой области (через `np.diff`).
